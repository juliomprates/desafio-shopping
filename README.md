# Desafio Shopping

Desafio da disciplina de Laboratório I do curso de Análise e Desenvolvimento de Sistemas da UNISINOS

Esse projeto visa implementar um sistema de gerenciamento de lojas de um Shopping pelo terminal

Utilizando:

- Conceitos do paradigma de Programação Orientada a Objetos: 
  - Atributos e Métodos
  - Associação entre Classes (Composição)

- Os 4 Pilares da Programação Orientada a Objetos:
  - Abstração
  - Encapsulamento
  - Herança e Polimorfismo

- Java (JDK 17.0.12)

Ao longo do semestre serei exposto a novos conhecimentos a respeito do paradigma de POO e consequentemente adicionando 
novas funcionalidades ao projeto.
